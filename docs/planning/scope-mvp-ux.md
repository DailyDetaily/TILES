# TILES 범위 선택 MVP · 2026-09-13

정리할 범위를 고르면 자동 추천을 확인하고 명시적으로 이동한다. 범위 선택은 파일·선택 폴더·연결 위치 전체가 같은 첫 화면에 있으며, 전체의 포함 위치와 개별 제외 상태가 보인다. 최초 연결은 자동으로 선택하지 않는다.

## 시각 기준
기존 DESIGN.md의 최종 지시와 현재 앱이 우선이다. 6×4 정사각형 벤토, 10pt 간격, 8pt 모서리, #4c92e9·흰색·검정·중성 회색, Pretendard/Manrope/Archivo Black과 TILES 워드마크를 유지한다. 비트맵이나 새로운 장식 자산은 필요 없다. 라이브 Refero는 NO_SUBSCRIPTION으로 조회되지 않아 제공된 기존 디자인과 번들 motion.md/craft-details.md를 보조 근거로 사용한다.

## 역할과 동작
- 왼쪽: 선택한 출처와 자동 추천 방식. 범위와 추천의 구분을 설명하며 프로젝트 생성은 기본 흐름에서 제외한다.
- 중앙: 범위 선택 → 고정 순서의 파일/추천 경로 목록 → 실제 원본·목적지와 만들 폴더 → 완료·되돌리기.
- 오른쪽: 실제 개수, 현재 단계, 다음 행동. 기본 화면의 주 CTA는 한 곳에만 두고 정리안 보기 → 이동안 확인 → N개 정리 → 새 정리로 바뀐다.
- 프로젝트 단서가 없으면 원래 위치 안에서 파일 종류별 폴더를 제안하고, 근거가 겹치면 사용자 확인을 기다린다.
- 초기 범위 확인은 메타데이터만 읽는다. 정리안 보기 이후 기기 내 내용 분석을 수행한다.
- 위치 변경은 포함 파일 전체 또는 파일별로 가능하며, 행의 순서와 ID를 유지한다.
- 범위를 다시 선택하면 현재 선택한 파일만 검토 묶음으로 전달하고, 이전에 보류한 다른 파일을 섞지 않는다.

## 모션
단계가 바뀔 때만 기존 링의 단계·집계·실행 타일을 순환시킨다. 빈칸을 열고 상하좌우 한 칸씩 이동한다. 추천과 최종 확인은 본문을 4×3으로 넓히며 완료는 3×3으로 접는다. 체크·개수·추천 위치 수정은 전체 배치를 재배치하지 않는다. 새 요청은 현재 착지 뒤 반영하고, 동작 줄이기는 즉시 최종 상태로 간다.

## 범위 표시
기본은 선택 폴더 바로 안의 일반 파일. 하위 폴더 포함은 명시적 옵션이다. 폴더 자체, 프로젝트 내부, 패키지, 링크, 숨김 및 기존 보호 정책 대상은 보존하고 제외 수를 알린다. 연결 위치 전체는 전체 디스크를 뜻하지 않는다. 500개 초과나 조사 한도는 첫 일부만 정리하지 않고 범위를 줄이도록 안내한다.

파일 모드에 놓은 폴더는 목록에 넣지 않고 선택 폴더로 연결하도록 안내한다. 연결한 상위·하위 폴더가 겹쳐도 명시적으로 제외한 하위 위치에는 들어가지 않는다. 완료 단계의 집계는 실제 이동·복원 결과를 표시한다.

## 검증
임시 파일만으로 범위·추천·이동·되돌리기 경로를 검증한다. 전체 자동화 테스트, 단계별 빈칸 경로 테스트, 네이티브 화면/창 크기/실제 입력 검증을 구분해 기록한다.
